# واجهة تصفح المنهج

أضيف المسار `#curriculum` ليحوّل نموذج المنهج الموحد من بنية داخلية إلى تجربة طالب مرئية.

## المسار

```text
المادة
  → الوحدة
    → الدرس
      → المهارة
        → المصادر الموروثة
        → البرومبتات المتاحة
        → عدد الأسئلة التي تقيس المهارة
        → المحاكاة المرتبطة بها إن وجدت
```

## قواعد العرض

- لا تعرض دروسًا أو مهارات لوحدة حالتها `unit-only`.
- لا تعرض زر محاكاة لمهارة لا توجد لها أسئلة في محاكاة مسجلة.
- تستخدم واجهة المهارة `curriculumIndex.getSkillContext` بدل إنشاء روابط يدوية جديدة.
- برومبت «اشرح هذه المهارة» يُبنى من Prompt Engine الحالي مع سياق المادة والوحدة والدرس والمهارة.
- يبقى مسار `#exam-pilot` وتنسيق الأسئلة الحالي كما هو.
