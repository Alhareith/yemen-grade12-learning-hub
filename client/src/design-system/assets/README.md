# V3 Visual Assets — Stage 3D

Runtime-ready visual assets derived from the approved design references.

## Rules

- Subject illustrations are visual assets, not functional icons.
- Keep Lucide for functional controls only; Stage 3E owns that contract.
- Use live Arabic text with the brand symbol instead of a rasterized full logo lockup.
- Do not recolor these assets for hover/selected states; UI state belongs to tokens/components.
- All files use WebP alpha transparency and fixed intrinsic dimensions to avoid layout shift.
- Render within the ranges recorded in `asset-manifest.json` unless a later measured component requirement is documented.

## Groups

- `brand/` — product symbol.
- `subjects/` — eight subject illustrations.
- `simulation/` — simulation/exam illustration.
- `actions/` — quick-action illustrations.

Stage 3M materialized the complete set into the repository.
